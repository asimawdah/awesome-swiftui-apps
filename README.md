# Awesome Swift & SwiftUI Apps

A curated list of open-source applications built with **Swift**, including **SwiftUI**, UIKit, and AppKit apps for iOS, iPadOS, macOS, and other Apple platforms. This list focuses on complete, usable applications—not frameworks, component libraries, design systems, or starter templates.

## AI & Machine Learning

- [fullmoon](https://github.com/mainframecomputer/fullmoon-ios) - Chat with private, locally running large language models on Apple devices. Built with Swift and SwiftUI. ([MIT](https://github.com/mainframecomputer/fullmoon-ios/blob/main/LICENSE))

- [macai](https://github.com/Renset/macai) - A native macOS AI chat client that connects to a wide range of model providers. Built with Swift. ([Apache-2.0](https://github.com/Renset/macai/blob/main/LICENSE))

- [Pocket AI Lab](https://github.com/ananasDDA/pocket-ai-lab) - Run open-source language models locally on iPhone using MLX, llama.cpp, Core ML, and Apple Foundation Models. Built with Swift and SwiftUI. ([MIT](https://github.com/ananasDDA/pocket-ai-lab/blob/main/LICENSE))


## Communication & Social

- [Broadcast](https://github.com/daneden/Broadcast) - A write-only social client for composing and publishing posts without an endless timeline. Built with Swift and SwiftUI. ([MIT](https://github.com/daneden/Broadcast/blob/main/LICENSE))

- [Element X](https://github.com/element-hq/element-x-ios) - A modern Matrix client for encrypted messaging and decentralized communication. Built with SwiftUI and the Matrix Rust SDK. ([AGPL-3.0](https://github.com/element-hq/element-x-ios/blob/develop/LICENSE))

- [Fabula](https://github.com/jasudev/FabulaItemsProvider) - A community app for sharing and communicating with developers. Built with Swift and SwiftUI for Apple platforms. ([MIT](https://github.com/jasudev/FabulaItemsProvider/blob/main/LICENSE))

- [Ice Cubes](https://github.com/Dimillian/IceCubesApp) - A feature-rich, open-source Mastodon client for browsing timelines and interacting with the fediverse. Built with SwiftUI. ([AGPL-3.0](https://github.com/Dimillian/IceCubesApp/blob/main/LICENSE))

- [IcySky](https://github.com/Dimillian/IcySky) - An open-source client for the Bluesky social network. Built with SwiftUI. ([AGPL-3.0](https://github.com/Dimillian/IcySky/blob/main/LICENSE))

- [Mlem](https://github.com/mlemgroup/mlem) - A native client for Lemmy, the federated link aggregator and discussion platform. Built with Swift and SwiftUI. ([GPL-3.0](https://github.com/mlemgroup/mlem/blob/main/LICENSE))

- [reddit-swiftui](https://github.com/carson-katri/reddit-swiftui) - A cross-platform Reddit client for Apple devices. Built with SwiftUI. ([MIT](https://github.com/carson-katri/reddit-swiftui/blob/master/LICENSE))

- [Signal](https://github.com/signalapp/Signal-iOS) - The iOS client for Signal, a private end-to-end encrypted messaging app. Built with Swift. ([AGPL-3.0](https://github.com/signalapp/Signal-iOS/blob/main/LICENSE))
